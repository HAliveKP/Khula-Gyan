## Handling checklist (applies to both legacy and Palika Guide)

- Save originals only in ignored `data/raw/` after checking the source's terms; never add them to Git without permission.
- Record the source's exact title, publisher, URL, access date, version/date, service, and scope.
- Keep extracted text linked to its source and page. Mark scanned, garbled, or incomplete pages for review.
- For Palika Guide: record municipality, district, province, ward, section. Never treat one municipality's charter as applicable to another.
- Never treat one district's citizenship checklist or one province's license instructions as nationwide rules.
- For Palika Guide: if a question names a municipality with no indexed charter, or names none, the app must ask which municipality or return not_found; it must never answer from another municipality's charter.
