## Source handling checklist

- Record the exact page/notice title, publisher, URL, access date, and any publication or update date.
- Verify that the source applies to the user's province and requested service.
- Do not infer that a government-hosted file is open-licensed. Ask the team to check reuse terms before committing a copy.
- Store page numbers with extracted text so every answer can cite its evidence.
