# Khula Gyan User Story Board

This board turns the project blueprint into small, reviewable tasks for a beginner team. The schedule is now **Day 1 = Oct 14 ... Day 8 = Oct 21** (8 days, code freeze on Day 8). Oct 22-25 is buffer only.

## How to use this board

- Start every task in **Backlog**. Move it to **In Progress** when someone takes it, and to **Done** only when its completion check passes.
- Keep work in small branches and pull requests. The local checkout currently tracks `branch`; the user-selected target for this setup work is `Hkp`. Agree on the team's long-term branch plan before creating shared `dev` or `main` branches.
- Every task should leave behind a visible result: a file, a working screen, a checked data source, or a recorded result.
- Do not commit API keys, `.env`, generated indexes, or source documents unless their usage terms allow it.
- Treat model scores and latency goals as things to measure, not promises. If evidence is weak or missing, the app must say it cannot answer from its sources.
- **Team (3 members)**: Member 1 = Data & Documents; Member 2 = Retrieval & Generation; Leader = Integration, UI, Evaluation, Repo, Deployment. Presenter/backup: **to be confirmed by a human**.
