# Resolve documented project decisions

Invoke the `decisions` subagent. It must research the repository documents and Git role history, quote exact evidence with file and line, and write `docs/decisions.md`. It must not change code/branches or run the pipeline. For silent documents, state `NOT IN DOCS` and a separate `PROVISIONAL` recommendation; never invent permission or a person's name. Leave publisher permission, presenter, and spending cap for human confirmation. Do not send email or make payments.
