Project idea: Khula Gyan is an open-source RAG assistant that answers Nepali government-procedure questions (driving license, citizenship, passport) in Nepali and English, using only official documents. Every answer has page-linked citations; if evidence is missing it refuses with "not_found". Stack: bge-m3 embeddings, ChromaDB, Streamlit UI, OpenRouter LLM, guard + eval harness. Full details are in README.md, AGENTS.md, and docs/. Current blocker: no approved civic source yet, so no verified cited answer; keep unmeasured metrics as "-".
